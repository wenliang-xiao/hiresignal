# 产品需求规格（Product Spec）

## 1. 产品定义

**HireSignal · 融资雷达**：面向校招/社招求职者的定向求职工具。

一句话：用融资数据锁定「有钱且在扩张」的 startup，用公开渠道直连「能拍板的人」（CEO/CTO/director 以上）。

## 2. 核心用户场景

1. 求职者搜索「按行业 × 近期 X 轮融资」的公司 → 得到正在扩张的 startup 列表。
2. 查看公司详情：融资历史、在招岗位、决策者（CEO/CTO）及公开触达渠道。
3. 通过公开渠道主动联系决策者（cold outreach），实现双向奔赴。
4. AI 问答：自然语言提问（如「最近 AI 赛道有哪些融资」）。

## 3. 功能清单

| 功能 | 优先级 | 状态 |
|------|--------|------|
| 公司搜索（关键词/行业/赛道） | P0 | 进行中 |
| 公司详情：融资历史 | P0 | 待数据源 |
| 公司详情：决策者（高管） | P0 | 待数据源 |
| 公司详情：联系方式（公开渠道聚合） | P0 | 待数据源 |
| AI 问答（自然语言） | P1 | 已跑通（无数据源时如实说明） |
| 订阅推送（关注赛道/轮次） | P2 | 计划中 |
| 雇主侧招聘曝光（变现） | P2 | 计划中 |

## 4. 商业模式

- **求职者：免费**。
- **变现方**：
  1. 正在招聘的 startup（雇主品牌曝光 / 招聘信息置顶 / 精准触达候选人）——主收入。
  2. 招聘相关服务商（猎头、简历服务、求职培训）——广告补充。
- 说明：数据采购（官方 API/MCP）是刚性成本，冷启动期需雇主付费覆盖，纯广告难以覆盖（见 [ADR-0003](./decisions/0003-business-model.md)）。

## 5. 合规边界（不可逾越）

- 只采**公开一手源**与**官方授权数据**，不爬商业付费库。
- 联系方式只聚合公开渠道，**不建私人邮箱数据库**。
- 人物信息脱敏，遵守 PIPL、数据安全法、反不正当竞争法。

## 6. 非目标（当前不做）

- 不做自建爬虫（见 [ADR-0002](./decisions/0002-official-mcp-over-crawler.md)）。
- 不做企业征信评级（需持牌）。
- 不做全文新闻转载（仅事实抽取）。
