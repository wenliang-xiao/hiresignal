# ADR-0002：数据层采用官方 MCP/API，放弃自建爬虫

- **日期**：2026-10-20
- **状态**：已采纳
- **决策者**：项目发起人

## 背景

初期尝试用爬虫抓取融资新闻（投资界等）并 LLM 结构化，跑通了 demo。

## 决策

**放弃自建爬虫**，数据层改为**官方 API/MCP 优先**：

- 鲸准 MCP/API：融资事件 + 创业公司 + 团队背景 + 行业标签。
- 企查查 MCP/API：工商 + 高管 + 官网。

## 理由

1. **稳定性**：爬虫反爬、改版、断源、合规风险高，撑不起「好用的搜索引擎」。
2. **收益低**：早期 startup 官网 SEO 差，搜索引擎难发现官网，爬虫抓到的信息质量低。
3. **合规**：官方 API/MCP 授权、可审计，规避反不正当竞争法「数据专款」风险。
4. **已有官方能力**：鲸准、企查查均提供标准 MCP（含官方 SKILL），正好覆盖融资事件与决策者。

## 影响

- 移除 `crawler/`、`extract/funding_event.py`、`pipeline.py`。
- 新增 `providers/`（jingdata.py、qcc.py），实现 `DataProvider` 接口。
- 数据采购成本成为商业模式必须覆盖的刚性成本（见 ADR-0003）。

## 例外

若未来官方源覆盖不足（如最新融资新闻时效），可评估「官方 API 为主 + 少量 RSS/公开源为辅」，需新增 ADR 说明，不得擅自引入大规模爬虫。
